## Released Architecture Baseline

### Sync authority

- PRISM SQLite is the canonical shared state.
- Mobile and desktop synchronize through `POST /api/v1/sync`.
- Mobile state and outbox persist in IndexedDB with a localStorage mirror.
- Stable mutation IDs make ambiguous retries idempotent.
- Per-entity versions detect stale concurrent writes.
- Current conflict policy is whole-entity server wins with conflict evidence retained by PRISM.
- Legacy full-state writes to `/state` and `/seed` are retired.

### Next invariant

A task belongs to Next if and only if `nextRank` is a non-empty string. `nextRank` also defines global order. `inGlobalBacklog` is a derived compatibility field, never an independent source of truth.

The original incident was a semantic split: desktop showed 16 items and mobile showed 8 because they used different membership rules. The repair verified the exact same 16 task IDs in the same order. Future parity proof must compare IDs and rank order, not counts alone.

### Mobile boundaries

- `src/sync/contract.ts`: domain/wire schema, mapping, ranks, Next invariant.
- `src/sync/indexedDbStorage.ts`: durable client state adapter.
- `src/stores/entityStore.ts`: optimistic entity repository and outbox reconciliation.
- `src/services/syncManager.ts`: transport, batching, timeout, retries, lifecycle triggers.
- `src/services/voiceBridge.ts`: LiveKit voice transport and test adapter.
- `src/services/foregroundService.ts`: Android background voice service.
- `src/stores/navigationStore.ts`: active view and task context.
- `src/stores/voiceStore.ts`: voice presentation state.

### Isolation

Entity sync, voice, timer/navigation, Android lifecycle support, and the Obsidian memory bridge have separate failure domains. Voice or memory failure must not block project workflows or synchronization.

## Open Risks and Blockers

- Physical installation and upgrade proof for 2.4.0 was not completed because no authorized ADB device was attached.
- PRISM sync currently relies on the private-network boundary and has no application-layer authentication or device revocation.
- PRISM SQLite backup, restore automation, retention, and process supervision remain open.
- Sync Schema 1 returns full reconciliation snapshots; delta paging is reserved but not implemented.
- Conflict handling has no user-facing inspector or keep-local workflow.
- The Android WebView currently permits cleartext/mixed content and grants permission requests more broadly than microphone-only.
- Obsidian local memory writes work, but Headless vault enrollment, cross-device Sync, vector retrieval, and automatic conversation summaries remain incomplete.
- The memory bridge source still contains a machine-specific default vault and optional Homebrew Node path; replace them with runtime home/tool discovery before relying on the CLI on another machine.
- Vite reports a JavaScript chunk larger than 500 kB.

## Do Not Relearn

- Matching Next counts is not parity; compare task IDs and order.
- `.prism_seed.json` is one-time migration input, not runtime state.
- Never reintroduce client full-state replacement.
- Wait for local persistence hydration before the first sync.
- Preserve the outbox across timeout, reconnect, and restart.
- A lost acknowledgement must retry the same mutation ID.
- Environment values are compiled into the mobile bundle; endpoint changes require rebuilding and reinstalling the APK.
- Do not use `Difaroo/samantha-voice` as this project's remote. `Difaroo/SAMANTHA_APP` is the project truth.
